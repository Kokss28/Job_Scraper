# 🎯 Screen 2: Experience & Career Tier Intelligence

---

## 🎯 Purpose & User Personas
Designed specifically for **Engineering Hiring Managers, Technical Recruiters, and Workforce Planners**. This screen provides deep quantitative insight into how talent experience is structured across the Indian tech job market, uncovering supply-demand mismatches and experience-to-skill expectations.

---

## ⚙️ Core Features & Analytics

### 1. Indian Tech Career Tier Breakdown
The platform maps raw numeric experience values into standardized Indian IT career bands:

```
┌─────────────────────────────────────────────────────────────┐
│ 🟢 Fresher & Entry Level (0 - 2 Yrs)  -> Trainee / Junior   │
│ 🔵 Mid-Career Professional (2 - 5 Yrs)-> Core IC Engineers  │
│ 🟣 Senior Engineer (5 - 8 Yrs)        -> Tech Leads / SMEs  │
│ 🟠 Staff & Leadership (8+ Yrs)        -> Architects / Eng Mg│
└─────────────────────────────────────────────────────────────┘
```
Each tier displays:
- Total active jobs open in India.
- Percentage share of the overall talent market.
- Dominant hiring sources for that tier.

### 2. Experience Distribution Curve
- **Histogram & Density Curve**: Visualizes experience thresholds from `0` to `20+` years.
- Identifies market concentration peaks (e.g., the massive spike for 3–5 year engineers in Bengaluru and Hyderabad).
- Displays statistical markers:
  - **Median Required Experience**
  - **Average Required Experience**
  - **Most Common Experience Bracket (Mode)**

### 3. Skill Expectations by Experience Level
- Interactive tool allowing recruiters to see how technical demands shift as experience climbs:
  - **0–2 Years**: Python, SQL, C++, Git, Basic DSA.
  - **3–5 Years**: FastAPI/Django, AWS, Docker, Microservices, CI/CD, PostgreSQL.
  - **6–8+ Years**: System Design, Distributed Systems, Kubernetes, Cloud Architecture, Mentorship, High-throughput caching.

### 4. Degree vs. Experience Cross-Tabulation
- Visual correlation showing how degree preferences (`B.Tech` vs. `MCA` vs. `Master's`) evolve between entry-level roles and executive positions.
